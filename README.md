# Student Management System

一个基于 Python 实现的学生成绩管理系统。

## 项目说明

这是一个 Python 初学阶段完成的练手项目，主要用于学习和实践 Python 基础知识。

通过完成本项目，练习了函数设计、列表与字典的使用、文件读写以及简单的数据管理逻辑。

项目功能较为基础，主要目的是记录学习过程和巩固 Python 编程能力。

## 功能介绍

- 添加学生信息
- 查询学生成绩
- 显示全部学生信息
- 文件保存学生数据

## 技术栈

- Python
- 文件读写
- 列表（List）
- 字典（Dictionary）

## 项目结构

```
student-management-system
│
├── main.py
├── students.txt
└── README.md
```

## 运行方式

运行：

```bash
python main.py
```

即可启动程序。
